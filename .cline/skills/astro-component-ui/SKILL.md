# Astro Component UI

Use this skill when the task involves Astro UI components.

## Scope
- Components: src/components
- Layouts: src/layouts
- Styles: src/styles/global.css (if needed)

## Workflow
1. Inspect existing component patterns and styling conventions.
2. Implement the requested component with compatible props.
3. Keep markup semantic and accessible.
4. Reuse shared components when possible.
5. Validate usage in pages.

## Requirements
- Match existing class naming and structure.
- Keep components focused and reusable.
- Avoid global style changes unless necessary.

## Output
- List files changed and a brief rationale.
